# 今後追加したい機能

|状況    | 対象                  | 内容                                  | 
|--------|-----------------------|---------------------------------------|
|        | L-VTT                 | 痛打条件を[6]などで指定し、攻撃判定で条件を達成した場合、痛打表示+色替え
|        | L-VTT                 | サツバツ!条件を[6,6]などで指定し、攻撃判定で条件を達成した場合、サツバツ!表示+色替え
|        | L-VTT                 | ナムアミダブツ!条件![6,6,6]などで指定し、攻撃判定で条件を達成した場合、ナムアミダブツ!表示+色替え
|        | L-VTT                 | 痛打条件,サツバツ!条件,ナムアミダブツ!条件で 5+ なら 5以上と判定できるようにする
|        | L-VTT                 | 痛打条件,サツバツ!条件,ナムアミダブツ!条件で 4+ なら 4以上と判定できるようにする
|        | L-VTT                 | 痛打条件,サツバツ!条件,ナムアミダブツ!条件で [6,5+] なら 6は1個以上+5以上が1個以上など複雑な判定をできるようにする
|        | L-VTT                 | 痛打条件,サツバツ!条件,ナムアミダブツ!条件で 攻撃以外の、射撃判定も含めるようにする
|        | L-VTT                 | 痛打条件,サツバツ!条件,ナムアミダブツ!条件で 攻撃以外の、精密判定も含めるようにする
